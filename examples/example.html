Architecture Flow Web Component

A custom element for rendering architecture diagrams using React Flow, with Shadow DOM isolation, JSON-driven data, theme support, and palette customization.

Demo A: External JSON

Load architecture data from an external JSON file via the src attribute.

External JSON 
<architecture-flow
  src="./architecture-basic.json"
  theme="system"
  palette="blue"
  interactive
  fit-view
  show-controls>
</architecture-flow>

Demo B: JavaScript Property API

Set diagram data programmatically via the data property.

Property API 
const flow = document.querySelector('#demo-b');
flow.data = {
  schemaVersion: "1.0",
  nodes: [...],
  edges: [...]
};

Demo C: Inline JSON

Embed architecture data directly in HTML using a <script type="application/json"> child element.

Inline JSON 
<architecture-flow theme="light" palette="teal">
  <script type="application/json">
    {
      "schemaVersion": "1.0",
      "nodes": [...],
      "edges": [...]
    }
  </script>
</architecture-flow>

Demo D: Theme & Palette Switching

Demonstrates runtime theme and palette switching without reloading the component.

Theme Controls 
<architecture-flow id="demo-d">
</architecture-flow>

<script>
  // Theme and palette can be changed via attributes or properties
  document.querySelector('#demo-d').theme = 'dark';
  document.querySelector('#demo-d').palette = 'violet';
</script>

Demo E: Runtime Data Controls

Load different datasets, clear data, and control viewport programmatically.

Runtime Controls 
// Available methods
element.setData(data);     // Set new data
element.getData();         // Get current data
element.reload();          // Reload from src
element.fitViewAsync();    // Fit view
element.resetViewport();   // Reset viewport position

Demo H: CSS Isolation Test

Verifies that Shadow DOM properly isolates the component from hostile global CSS.

CSS Isolation 
/* Hostile CSS applied globally - should NOT affect component */
* { box-sizing: content-box; }
button { font-size: 40px; border: 8px solid red; }
svg { fill: hotpink; }

/* Architecture Flow should still render correctly inside Shadow DOM */
